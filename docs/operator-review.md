# Optional semantic operator adapter groundwork

Select a `cert-manager.io/v1` Certificate and run `:operator-review`. The explicit read captures its context, exact GVR, namespace, name and UID before creating a pinned connection. Each named GET is bounded to three seconds and the collection to eight seconds. The adapter currently performs at most two reads (within the contract's three-read maximum): the selected Certificate and its named `spec.issuerRef` Issuer or ClusterIssuer. It never lists resources or reads Secrets, private keys, arbitrary provider URLs, annotation values, status messages or credential configuration.

This adapter selects exact `cert-manager.io/v1` Certificate semantics. Unknown groups, incompatible versions and other kinds retain the existing generic CRD browser, YAML, describe and configured custom jumps; they are unsupported semantics, never inferred faults. It does not automatically register a renderer, scan adapters, run CLI programs, install controllers or execute probes.

Ready=True means the controller reports that its readiness checks succeeded. It is not independently verified live TLS, private-key match or recoverability evidence. Ready=False means the controller reports not ready. Issuing=True reports issuance required; Issuing=False reports not issuing and is not itself a fault. Missing observedGeneration is unknown; an older observedGeneration is stale, and a future generation is unknown. Unknown condition types are counted without interpreting their polarity. Duplicate or malformed known conditions are unknown schema evidence.

Projection retains at most 128 conditions and a fixed allowlist smaller than 32 other reported facts, with at most 256 bytes per string. It includes captured generation, reported notBefore/notAfter/renewalTime/revision, Secret name reference only, and source/read/capture times with UID/resourceVersion. Oversized or malformed condition arrays are explicitly partial. Missing fields are Unreported. Raw objects and free-form status messages are never retained.

The issuer relation is a declared name reference. An exact named GET can observe its target UID, but issuerRef supplies no source UID link, so ownership remains unverified. Default group (`cert-manager.io`) and kind (`Issuer`) follow the provider contract. Issuer is read only in the Certificate namespace; ClusterIssuer uses its cluster-scoped named endpoint. Wrong schema or identity, denied reads and proxy 404s remain distinct coverage. Absence requires a structured Kubernetes 404 with matching code/reason/group/resource/name; a plain proxy 404 remains unknown.

Tab/Shift-Tab and 1–4 switch the native single-pane tabs; `/` searches, `r` explicitly refreshes, `c` cancels and Esc returns. Captures and per-tab search/scroll survive failed refresh and disconnect. Late replies are rejected after Stop, a new generation or destination change. At 80×24 and 40×12, identity, the controller-report limitation, coverage and keyboard controls remain readable without icons or color. Full source identity is in Sources. Suggested actions return to generic YAML/describe; if the existing custom-jump configuration contains a valid rule for the selected GVR, Relations explicitly offers the existing browser Enter workflow. The adapter never executes or changes that configuration.

Provider semantics were checked against live upstream source on 4 October 2026: [Certificate API](https://github.com/cert-manager/cert-manager/blob/master/pkg/apis/certmanager/v1/types_certificate.go), Git blob `b0149ba99337d217b2b346e029b62471ccb72fef`, and [IssuerReference defaults](https://github.com/cert-manager/cert-manager/blob/master/pkg/apis/meta/v1/types.go), Git blob `d13760aef2fa8c8399f5eb10aebc00971ce0abd0`. In particular, Ready and Issuing are provider-specific conditions; False has no universal fault meaning.

This is optional groundwork for #71, not completion of TK27. Demand validation, real-cluster cert-manager compatibility, operator evaluation and broader adapters remain open. Local HTTP/fake API and simulated terminal tests do not constitute a live cert-manager deployment or human validation study.
